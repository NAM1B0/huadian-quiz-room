# 华电公共题库练习室 v1.0.4 · iOS 26+

将 Windows v1.0.4 的刷题逻辑移植到原生 iPhone 应用，内置 563 道题与原始 PDF，离线使用。

- 原生底部导航、单手翻题、分组题号面板；选项整行可点，支持系统大字体、深色模式和横竖屏。
- 练习答案预览、即时判分、按规则自动下一题；多选仅在普通练习中选全且正确时自动跳转。
- 考试按部分打乱、前台计时、断点续做、全部作答后交卷并锁定答案。
- 练习按题型与部分汇总；考试记录可编辑勾选删除，删除前自动备份。
- 两类错题独立保存，分别设置“答对后自动移出”。
- 导出及恢复 iOS 备份，也可导入 Windows 版导出的 SQLite 学习备份。两端各自保存进度，不自动同步。

下载 `huadian-quiz-room-v1.0.4-ios26.ipa`，通过 **AltStore Classic / AltServer** 等工具用自己的 Apple 账户重签安装。此包要求 **iOS 26.0 或更新版本、iPhone**。安装及刷新步骤见 [iOS 使用说明](https://github.com/NAM1B0/huadian-quiz-room/blob/ios-v1.0.4/ios/README.md)。

验证以 GitHub Actions 的原生编译、单元测试及 iPhone 13 Pro 模拟器 UI 测试为依据；尚未在实体 iPhone 上验证侧载。Windows v1.0.4 下载包保持原样。
