# 华电公共题库练习室 v1.0.4 · iOS 修订 2

修复手机侧载后“数据 → 题库原文”出现空白的问题，版本为 **1.0.4，构建号 10402**，支持 iOS 26+ iPhone。

- 包内 PDF 改用英文资源名，避免 Windows 侧载工具解压、重签、打包时的文件名兼容问题。
- PDF 阅读器等待有效屏幕尺寸后再缩放和定位，支持竖屏、横屏和连续滚动。
- 数据页与答题页的原文入口均使用新阅读器；答题页会定位到对应原文页。
- 增加当前 PDF 页码、导出 PDF、加载失败提示及重试按钮。

更新前先在“数据 → 导出学习记录”保存备份，再使用原来的 Apple 账号及签名 App ID **覆盖安装**。安装后可在“数据 → 版本”确认 `1.0.4 (10402)`。答题规则及记录格式沿用 v1.0.4。

下载附件中的 `huadian-quiz-room-v1.0.4-ios26-build10402.ipa`，通过 Sideloadly / AltStore Classic / AltServer 等工具重新签名安装。

此安装包已由用户在实体 iPhone 侧载确认“数据 → 题库原文”正常显示并可上下滚动。14 项单元测试和 6 项原生 UI 测试已通过，补充的原文完整界面回归在发布时仍在运行；测试范围、状态链接与实际截图见 [验证记录](https://github.com/NAM1B0/huadian-quiz-room/blob/v1.0.4-ios.2/ios/TESTING-10402.md)。
