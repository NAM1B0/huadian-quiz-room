# 华电公共题库练习室 · iOS

移植自 Windows v1.0.4，原生 SwiftUI，最低 iOS 26.0，面向 iPhone。题库和原始 PDF 均随应用内置，离线使用，无需账号或手机上的 Python 服务。Windows 版保持不变。

## 安装

本目录的构建产物 `huadian-quiz-room-v1.0.4-ios26.ipa` 是真正的 arm64 iOS 应用，未使用开发者证书签名，需要用户自行重签。不能直接点击 IPA 安装，也不能安装在 Android、Windows 或 iOS 25 及更早版本。

1. 在电脑按 [AltStore Classic 官方教程](https://faq.altstore.io/altstore-classic/altserver) 安装 AltServer，并在 iPhone 上安装 AltStore Classic。
2. 将 IPA 保存到 iPhone 的“文件”应用，在 AltStore Classic 的 My Apps 中点 `+` 选择它，使用自己的 Apple 账户完成侧载。不要把密码提供给本项目。
3. 按 AltStore 提示启用开发者模式、信任签名并定期刷新。免费账户通常需要每 7 天刷新，且有同时侧载数量限制，详见 [AltStore 官方说明](https://faq.altstore.io/altstore-classic/your-altstore)。这里指 Classic，不是 AltStore PAL。
4. 更新前从“数据 → 导出学习记录”备份。使用同一账户、同一签名 App ID 覆盖安装有助于保留数据；删除应用会删除其本机数据，签名工具改变 App ID 也可能安装成另一个应用。

只在用户自己的设备上重新签名安装。此项目没有 Apple 开发者分发证书，不提供已签名的企业证书包，也不要求越狱。

## 手机适配

- 原生导航和底部标签，进入题目后隐藏标签栏，把空间留给题目。
- 底部固定“上一题 / 题号 / 下一题”；按题库部分分组的题号在弹出面板中查看，可输入原题号筛选。
- 触控目标至少 44 pt，选项整行可点；题干、选项完整换行，支持系统大字体、深色模式、横竖屏与安全区域。
- 答案预览开关每次进入默认关闭；浏览答案不写作答记录。
- 原题号不变；漏选灰色、错选红色、答对绿色，同时以符号与文字标明状态。考试交卷前仅显示蓝色已答。

| 场景 | 单选、判断 | 多选 |
| --- | --- | --- |
| 普通练习 | 选对自动下一题 | 全部选对自动下一题 |
| 考试交卷前 | 选择并保存后自动下一题 | 手动下一题 |
| 练习错题 | 选对自动下一题 | 手动下一题 |
| 考试错题 | 选择并保存后自动下一题 | 手动下一题 |

每次自动下一题保留短暂停顿供查看反馈，最后一题不会自动交卷。手动导航、进入后台会取消尚未执行的自动跳转。考试只累计在前台答题时的时间，离开答题页或进入后台暂停。

## 记录与备份

普通练习按最新选择统计，显示每种题型及其六个部分的已练习数、答对数、正确率，不保存逐次操作日志。考试可按场次编辑删除，删除前自动备份；对应考试错题随该场考试删除。其余 v1.0.4 规则一致。

数据以带版本和题库标识的 JSON 原子写入应用沙盒，关闭后保留。两类错题的复习结果独立于原始答案；“答对后自动移出”分别设置，默认关闭。

“数据 → 导入备份”可读取 iOS 导出的 JSON，或电脑版“数据与备份”导出的 SQLite。导入会先校验、提示替换，再备份手机当前数据。手机与电脑不自动同步；iOS 导出的 JSON 不能直接导回原 Windows v1.0.4。旧电脑版的逐次事件日志不导入，最新练习答案、考试与错题记录保留。

## 构建与验证

需要 macOS、Xcode 26 或更新版本以及 iOS 26+ SDK。在 Windows 上不能直接编译 iOS 原生二进制。

```sh
python3 ios/tools/generate_project.py
open ios/HuadianQuiz.xcodeproj
```

项目包含应用、单元测试与原生 UI 测试，不使用第三方依赖。应用标识为 `io.github.nam1b0.huadianquiz`，版本 1.0.4，构建号 10401。真机开发可在 Xcode 选择自己的 Team；CI 使用 `CODE_SIGNING_ALLOWED=NO`。

GitHub Actions 的 `iOS 26 build and phone checks` 工作流在 macOS 上创建 iPhone 13 Pro 模拟器，执行数据逻辑与 UI 测试、导出原生截图，最后归档 arm64 真机应用并生成 IPA、SHA-256 和构建信息。仅在编译及测试成功后才上传 IPA。模拟器验证不能替代实体 iPhone 上的侧载和使用验证。
