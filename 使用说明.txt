华电题库练习室 · 2026 版
中国华电集团有限公司高校毕业生招聘考试公共与行业知识题库

一、如何打开
1. 如果拿到的是压缩包，请先把整个文件夹解压到可写的位置。
2. 双击“启动华电题库.cmd”。程序会打开默认浏览器。
3. Windows 便携发布包已附带 Python；无需安装 Python、联网或登录账号。
   GitHub 源码包不含运行环境，需安装 Python 3.12+ 后运行 python server.py --open。
4. 默认地址：http://127.0.0.1:18926。若端口被占用，程序会自动选用可用端口。
   实际地址保存在 data/运行地址.txt。
5. 不要直接打开 web/index.html，启动文件会同时运行记录保存服务。
6. 结束时，进入“数据与备份”，点击“保存并关闭程序”。
   只关闭浏览器也不会丢失已保存的答案，后台程序仍会运行。

二、题库
原文件：附件2_20260914225451.pdf，2026 年 9 月版。
题库开始于印刷页码 39，对应 PDF 文件第 40 页，至印刷第 160 页。
共 563 道：单选题 245 道，多选题 181 道，判断题 137 道。
原题号依次为：单选 1–245，多选 246–426，判断 427–563。
每种题型均保留六个部分：形势政策、企业文化、公司概况、新型电力系统、品牌建设、电力基础知识。
其中多选和判断的第六部分原文名称为“电力系统基础知识”。
第六部分的小分类也保留在题干上方。
参考答案忠实于原 PDF，未编造解析。可用“核对原文”打开对应页。

三、练习
不计时。每次选择立即保存并显示对错，答题卡绿色为正确，红色为错误。
可以反复修改选择。多选题每次勾选都会重新判定；必须完全选对，少选、多选均记为错误。
重新进入保留上次的选择。历史每次选择可在“做题记录 → 练习与复习记录”中分页查看。

四、考试
同一题型是一份完整试卷；每个部分内部随机排序，六个部分的顺序保持不变。
原题号不变，选项顺序不变。同一题型最多保留一份未交卷的试卷。
未交卷时蓝色题号表示已答，不显示对错；允许更改选择或清除选择。
累计在可见考试答题页面的时间，离开或隐藏页面时暂停。没有倒计时或考试时限。
每 5 秒同步一次计时。突然断电等异常情况下，最多可能损失最近数秒的计时。
所有题目均作答后，才能点击“交卷并查看结果”。弹窗确认后锁定答案。
交卷后按每题等权折算百分制，属于学习统计，非官方评分规则。
未交卷：从普通入口和考试记录入口都能继续同一份试卷，题序不变。
已交卷：只在考试记录中回顾；从普通入口开始会创建全新试卷。
换题、退出、重启均不会主动删除任何已保存的考试。

五、错题
练习错题：对应正常练习的最新错误答案。正常练习中改对或清空，自动移出。
考试错题：按“考试场次 + 题号”单独保存。以后考试答对，不影响以前的错题。
两类错题各自拥有“复习答对后自动移出”开关，默认为关闭，设置永久保存。
开关关闭：在错题集里做对仍保留，标记“复习已答对”。
开关开启：之后的复习作答完全正确时，移出当前这一条错题。
开启开关本身不会批量移除过去已复习答对的条目；再次正确作答才会移出。
错题复习不会覆盖正常练习答案或原考试记录。即使移出，原始记录也保留。
正常练习后来再次作答错误时，对应练习错题会重新出现。

六、数据与备份
记录数据库：data/学习记录.sqlite3。
这是程序目录中的文件，不依赖浏览器缓存；清理浏览器缓存不会删除学习记录。
正常使用不设自动过期和自动清理。切勿删除 data 文件夹。
程序启动时会在 data/自动备份/ 保存当天第一次启动前的记录快照。
通过界面“保存并关闭程序”会生成 data/退出时备份.sqlite3。
可以在“数据与备份”点击“导出完整备份”，下载当前一致性数据库快照。
迁移：先通过界面关闭程序，再复制整个程序文件夹到新的 Windows 电脑。
恢复：先通过界面关闭程序；将当前 data 文件夹重命名留作备份，创建新的 data 文件夹，
      把所需 .sqlite3 备份复制进去并命名为“学习记录.sqlite3”，然后重新启动。
      恢复会回到该备份时刻。请保留恢复前的原文件夹，以便找回较新的记录。
磁盘损坏或手动删除不能靠“永久保存”避免，建议重要记录另存到其他磁盘。

七、文件说明
启动华电题库.cmd / launch.ps1：启动入口。
runtime/：附带的 CPython 运行环境及许可，不需要单独安装。
server.py：仅依赖 Python 标准库的本地服务，绑定 127.0.0.1。
web/：界面文件。bank.json：经核对的 563 道结构化题目及答案。
source/题库原文.pdf：原 PDF 副本。
tools/：题库提取、校验、测试与打包脚本，正常使用无需运行。
data/：首次启动时自动创建的个人记录，不要删除。

适用 Windows 10/11 64 位。程序完全在本机运行，不上传学习记录。
